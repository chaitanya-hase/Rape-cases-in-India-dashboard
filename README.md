# Rape Cases in India Dashboard – Power BI
## Project Overview
This Power BI dashboard analyzes data on rape cases reported across India, providing a comprehensive overview of trends, hotspots, and patterns over various time periods. The goal is to inform policy decisions, raise awareness, and support law enforcement in addressing the issues related to sexual violence.

##  Objectives
- Visualize Trends: Track the number of reported rape cases over time.

- Geographical Insights: Identify states or regions with higher rates of reported incidents.

- Age and Gender Demographics: Understand the age and gender breakdown of victims.

- Case Outcomes: Analyze the resolution of cases 

## The data used in this dashboard is sourced from:

- National Crime Records Bureau (NCRB)

- Publicly available government data on sexual crimes
- The data includes fields like:

  - State/Region

  - Year/Month

  - Age of Victim

  - Outcome of Case (e.g., Conviction, Pending, etc.)

  - Gender of Victim

- The dataset is cleaned and transformed using Power Query Editor in Power BI.

##  Key Features
- State-wise Analysis: Bar charts and maps to show the distribution of cases across different states and regions.

- Time Trends: Line charts to visualize the change in reported cases over time.

- Demographic Insights: Pie charts and tables to show the age and gender of victims.

- Outcome Tracking: Track the status of cases from report to conviction using stacked bar charts.

## Tools & Technologies Used
- Power BI Desktop

- Power Query Editor


## Insights Derived
- Geographical Insights: Some states show disproportionately high numbers of reported cases, which may require further attention and intervention.

- Case Outcomes: Conviction rates may vary across regions, highlighting areas where the justice system may need reform.

- Trends Over Time: Increases or decreases in reported cases, potentially linked to socio-cultural changes or legal reforms.
